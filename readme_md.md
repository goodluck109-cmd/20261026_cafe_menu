# ☕ Café Lumière (카페 루미에르) - 웹 주문 앱

> **따뜻함과 감성이 쉬어가는 공간**  
> `Café Lumière`는 웹 브라우저에서 메뉴를 확인하고, 자유롭게 장바구니에 담아 주문을 진행할 수 있는 감성 카페 주문 웹 애플리케이션입니다.

---

## 🌟 주요 기능 (Key Features)

- 🍹 **카테고리별 메뉴 필터링**: 전체 메뉴, 음료(Beverages), 디저트 & 아이스크림으로 한눈에 분류하여 감상 및 선택 가능
- 🛒 **실시간 장바구니 결제 계산**: 메뉴 추가/삭제 시 하단 바에서 실시간 총 금액 및 수량 자동 산출
- 📋 **주문 내역 상세 모달**: 선택한 메뉴 목록과 총 금액을 모달 창을 통해 한눈에 재확인
- 🔊 **효과음 & 웹 음성(TTS) 지원**: 
  - 버튼 클릭 시 나오는 깔끔한 오디오 효과음
  - Web Audio API를 활용한 잔잔한 배경음악(BGM) 재생 기능
  - 주문 완료 시 나오는 따뜻한 음성 안내 메세지 ("주문해 주셔서 감사합니다.")
- 📱 **반응형 웹 디자인**: 모바일, 태블릿, PC 모든 기기 환경에 최적화된 웹 디자인 (Tailwind CSS 적용)

## 🚀 실행 방법 (How to Run)

1. 저장소를 클론(Clone)하거나 Zip 파일로 다운로드합니다.
2. 모든 이미지 파일과 `index.html` 파일이 **동일한 폴더**에 위치해 있는지 확인합니다.
3. `index.html` 파일을 더블 클릭하여 크롬(Chrome)이나 최신 브라우저에서 실행합니다.
